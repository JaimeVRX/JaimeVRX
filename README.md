# 👾 Hey, I'm Jaime

### Hobby developer • FiveM systems • Independent projects

I'm a developer from the Netherlands who enjoys building practical tools, learning new technologies, and turning ideas into working software.

My work currently spans **FiveM development** for RedLine Roleplay and early-stage independent projects in security and communications software.

---

## 🚀 Current Projects

### 🔴 RedLine Roleplay
A Dutch FiveM roleplay server and the main focus of my game-server development. I build and adapt Lua resources, staff tools, integrations, and player-facing systems around the server.

**Focus:** FiveM, Lua, ESX, ox_lib, ox_inventory, oxmysql, NUI

### 🛡️ AimGuard
An experimental FiveM anti-cheat prototype focused on aim-related signals and shot analysis. It is still under development and is **not production-ready**; detections and integrations need further testing.

**Focus:** Lua, FiveM, MySQL, NUI

### 💜 Kyvori
A private-alpha communication platform project. The current foundation includes a React and TypeScript client and a Fastify API, with PostgreSQL-backed account and messaging features in development. It is a work in progress, not a public-release product.

**Focus:** TypeScript, React, Fastify, PostgreSQL, Socket.IO, Tauri

### 🐉 Valyrix Studios
My independent studio identity for experiments, custom resources, and software projects.
